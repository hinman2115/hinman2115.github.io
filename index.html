ABOUT

What I actually do day to day

I'm an iOS developer with a year of hands-on experience building and maintaining production apps as part of a development team, primarily working in Swift and UIKit, with SwiftUI where it fits.

Day to day that means implementing UI to match design specs, wiring up REST API integrations, parsing and modeling JSON responses, handling navigation flows, and spending real time in the debugger tracking down and fixing bugs — then shipping the fix.

I like the parts of the job that don't show up in a screenshot: making a list scroll smoothly, making an API failure feel like part of the design instead of a crash, and making the next person's pull request easier to review.
